# GitHub Pages: LoremWerk online schalten

1. Öffne https://github.com/TheYogi1999/LoremWerk/settings/pages
2. Unter **Build and deployment → Source** wähle **GitHub Actions**.
3. Prüfe https://github.com/TheYogi1999/LoremWerk/actions ; bei Bedarf Workflow **Publish LoremWerk to GitHub Pages** → **Run workflow**.
4. Wenn die Veröffentlichung erfolgreich ist: https://theyogi1999.github.io/LoremWerk/

Die GitHub-Verbindung kann Dateien hochladen, aber die Pages-Einstellung selbst nicht umstellen. Diese einmalige Aktion ist deshalb nötig.

**Datenschutz:** Bei Nutzung der GitHub-Pages-Adresse werden Programmdateien von GitHub geladen, der eingegebene technische Text bleibt in deinem Browser; die App ruft dafür keine externe API auf.
